# CamLensSim

一个运行在浏览器里的摄影光学实验室。通过室内静物、室外高山湖畔、室外人像、林间知更鸟四个实时三维场景，探索焦距、光圈、传感器尺寸、对焦距离、特殊镜头与自由机位的关系。

在线访问：[CamLensSim](https://pilotmiku.github.io/CamLensSim/)。

当前是可扩展的第三阶段 MVP。原始需求保留在 [writing-block.md](writing-block.md)。无后端、无 API Key、无远程场景资源，场景在本地构建；人物头部使用随源码提供的 CC0 人体网格，其余几何、材质和灯光由本地程序生成。

## 本地运行

需要 Node.js 22.12+，推荐 Node.js 24。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，通常为 http://127.0.0.1:5173。

```sh
npm test                 # 光学、机位、状态、场景几何与资源释放测试
npm run typecheck        # TypeScript 检查
npm run build            # 检查类型并生成 dist/
npm run preview          # 预览生产构建
npm run test:e2e         # 桌面 / 移动端 Chromium 浏览器验证
```

浏览器测试默认使用本机 Google Chrome；如果使用 Playwright 自带 Chromium，先运行 `npx playwright install chromium`，然后执行 `PLAYWRIGHT_CHANNEL=chromium npm run test:e2e`。

## 自由机位

取景器就是一个可以走进去的摄影棚：

- 桌面端：`W` `A` `S` `D` 前后左右移动，`J` / `K` 水平转向，`I` / `O` 俯仰，`R` / `F` 升降，`Shift` 加速、`Alt` 慢速。方向键也可以转向。
- 在画面上按住拖动可环视，滚轮前后推拉；短按（不拖动）则对焦到该位置的物体。
- 手机 / 平板：左右两个虚拟摇杆分别控制移动与转向，左侧的 `+` / `−` 控制机位升降。也可以在工具栏手动开关摇杆。
- 「自动跟焦」开启时，焦点锁定在画面中的物体上，移动机位会持续重算对焦距离；关闭后是手动对焦，机位移动后需要重新对焦。
- 「复位机位」回到默认取景；「重置参数」恢复全部拍摄设置。

## 已接通的功能

- 焦距、光圈、对焦距离、机位距离 / 高度：滑块调整，或输入数字并按 Enter / 移开焦点确认。
- 全画幅、APS-C、M4/3、中画幅传感器；相机纵横比与取景器同步变化。
- 22 支镜头：自定义 10–1200 mm f/0.95–32、大三元 / 小三元变焦、常见定焦大光圈、300 f/2.8 与 600 f/4 超长焦、移轴、鱼眼、折返；自动应用焦距、最大光圈与最近对焦距离限制，光圈按三分之一档取整。
- 四个按 `预览/` 参考图重建、带独立光源的场景：**室内静物**（支持光追的封闭工作室、真实开口的窗户、窗外枝叶、白花陶瓶、茶具、木桌与垂坠亚麻布）；**室外高山湖畔**（侵蚀山脊与积雪、实时湖面倒影、树荫、草甸野花与步道）；**室外人像**（樱花步道、CC0 人体头部网格、黑长直发、水手服 JK 与百褶裙、条纹过膝袜与春日下午逆光）；**林间知更鸟**（实际尺度的连续鸟体、分层羽毛、覆苔树枝、地衣与多层树林）。
- 场景标题旁的「参考图」可查看原图，便于对照构图；参考图不会替代三维取景器。
- 对焦成功会播放短促双音，可通过取景器的“音效”按钮静音；声音由浏览器本地合成，无需加载音频文件。
- 点击画面中的物体对焦；点击距离示意条中的物体标记对焦。
- 实时水平 / 垂直 / 对角视角、裁切系数、35mm 等效焦距、景深近界 / 远界 / 总范围、超焦距与放大率。
- 基于有符号弥散圈、光圈叶片多边形核、衍射与屏幕空间采样的景深预览，可关闭对照。
- “模式”可切换 **实时 / 光追**。光追基于 [three-gpu-pathtracer 0.0.24](https://github.com/gkjohnson/three-gpu-pathtracer/tree/v0.0.24)（MIT）与 three-mesh-bvh：将实例化草木烘焙为可求交的 BVH 几何，最多计算 6 次反弹及透射路径，提供反射、折射、几何遮挡阴影、间接光照和薄透镜景深。湖面在光追中使用水的物理材质。机位停止后逐步累积至 128 次采样，每次完整采样后使用深度与表面颜色引导的三轮保边降噪，降低 28 次等低采样下的颗粒；降噪强度随采样数减弱，调整参数后重置，滤波结果不写回原始累积。首次构建场景需要等待，首个采样完成前显示实时画面。均衡 / 节能档采用 70% / 45% 的渲染分辨率。
- 光追目前支持普通透视及镜头平移；鱼眼、折返、镜头倾斜使用实时模式，并显示提示。光追与实时模式使用同源的晴天下午天空环境，自定义光栅着色器会转成物理材质；暂未将实时模式的衍射、ISO 颗粒与暗角后处理接到光追输出。设备不支持浮点渲染或初始化失败时显示原因并回到实时预览。
- 四个场景统一为晴天下午 16:00，各有六面天空盒与同源 HDR 环境光，太阳高度约 28°。每个场景提供世界坐标固定的太阳和暖色聚光灯，光源不跟随机位移动。室内通过真实窗洞采光，窗格与枝叶的遮挡产生丁达尔光束。实时与光追共用稳定的单次体积散射：沿视线进行世界空间光线步进，用各光源的阴影贴图判断遮挡，并计算透射衰减；聚光灯计算有限光锥的射线交点，再以稳定的中点步进积分，避免窄光束颗粒化；半分辨率渲染、按深度上采样，均衡 / 节能档分别使用 64 / 32 步。光追在降噪后叠加体积光，不再随机采样空气体积，避免低采样时雾中闪点；体积光是混合近似，不计算多次散射与体积间接光。
- 恒定曝光预览；关闭后光圈、快门与 ISO 会真实改变画面亮度，高 ISO 带颗粒，镜头带暗角与衍射软化。
- 移轴（倾角与水平 / 垂直偏移）、鱼眼等距投影、折返环形（甜甜圈）光斑等特殊光学。
- 三分构图线、参数重置、机位复位、帮助说明与节能渲染档位。
- 响应式布局；无 WebGL 时保留光学计算和参数操作，显示明确的预览不可用提示。

## 工程结构

```text
src/
  domain/       核心参数、机位数学、类型定义，统一物理单位
  data/         传感器、镜头、光圈档位与默认配置
  optics/       无 UI / Three.js 依赖的光学函数及单元测试
  state/        React reducer、参数约束、跟焦与共享状态
  controls/     自由机位输入、平滑积分与摇杆接口
  scenes/       场景接口、注册表、四个程序化场景、建模工具、实例化枝叶、纹理与环境
  renderer/     相机投影、渲染生命周期、景深与曝光后处理
  components/   参数面板、取景器、摇杆、数据读数、距离示意图
  App.tsx       页面组装
e2e/            真实浏览器的交互、渲染与降级验证
.github/        GitHub Pages 验证与部署工作流
```

采用 React + TypeScript + Vite + Three.js + Vitest。共享状态使用轻量的 Context / reducer；样式使用原生 CSS，减少框架和运行时依赖。新增场景实现 `SceneDefinition` 并加入 `scenes/registry.ts` 即可；新增器材修改 `data/equipment.ts`。详细边界见 [架构说明](docs/architecture.md)。

## 光学约定与限制

世界坐标、机位距离和对焦距离使用 **米**；焦距、传感器尺寸与弥散圈使用 **毫米**。镜头看向自身光轴，室内默认机位在 `(0, 1.20, 4.60)`、俯角 2°，主体中心平面为 Z = 0。

视角为 `2 atan(传感器边长 / (2 × 焦距))`，这是无限远对焦的标称视角。实际渲染使用对焦距离对应的像距 `v = f·s/(s−f)`，因此近距对焦时会轻微收窄视角，即对焦呼吸。裁切系数使用全画幅与当前传感器的对角线之比；等效焦距用于比较对角视角，**不代表景深或曝光等效**。

景深使用薄透镜模型，容许弥散圈 `c = 传感器对角线 / 1500`，对应约定观看条件下的可接受清晰标准，不是像素大小。令焦距为 `f`、光圈 f 数为 `N`、对焦距离为 `s`，计算时全部换算为毫米：

```text
q = f² / (N × c)
超焦距 H = q + f
近界 Dn = q × s / (q + s − f)
远界 Df = q × s / (q − s + f)，s ≥ H 时为 ∞
物距 u 的弥散圈直径 = f² × |s − u| / (N × u × (s − f))
```

使用 `q = H − f` 的边界公式，与上述像面弥散圈定义保持一致；在超焦距处远界为无穷远、近界为 H/2。

渲染在几何弥散圈之外再叠加波长 550 nm 的艾里斑 `2.44 × λ × N`，两者按平方和合成，因此 f/16 之后即使景深很深，绝对锐度也会被衍射限制。光圈叶片数会改变焦外光斑的多边形形状。

曝光值 `EV₁₀₀ = log₂(N² / t) − log₂(ISO / 100)`。开启「恒定曝光预览」时只改变景深、不改变亮度；关闭后按参考曝光归一化。画面还包含随光圈 / 焦距变化的暗角与随 ISO 增强的颗粒。

真实相机主平面位置、复杂像差、滚动快门、运动模糊与相机传感器降噪不建模。直线投影只使用薄透镜像距修正；鱼眼镜头使用等距（equisolid）投影 `r = 2f·sin(θ/2)`，移轴镜头通过斜向视锥实现平移、通过倾斜焦平面近似沙姆定律，折返镜头用环形孔径近似中心遮挡。

**画面虚化是近似视觉模拟。** 渲染将场景保存在线性 HDR 中，用全分辨率深度计算有符号弥散圈，再在半分辨率下按光圈多边形核做散点 / 汇聚采样，最后只在真正离焦的像素上混合，因此焦内细节不会被背景糊掉。最大散焦半径与采样次数有上限（均衡档 44 次、节能档 14 次），不是物理光线追踪，也不模拟真实镜头的像差、光斑渐晕与遮挡衍射。景深数据与渲染共用参数，计算结果不会因关闭预览或选择节能档而变化。

均衡档限制 DPR ≤ 1.75、4×MSAA；节能档 DPR ≤ 1、关闭 MSAA。静态场景按参数或容器变化请求绘制，空闲时不持续刷新；移动相机时按输入逐帧更新。

## GitHub Pages

1. 将本目录作为 Git 仓库推送到 GitHub，默认分支为 `main`。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 或手动运行工作流。工作流会安装锁定依赖、执行类型检查和单元测试、构建并部署 `dist/`。PR 只执行验证。

工作流通过 `actions/configure-pages` 获取实际基础路径，兼容项目子路径与用户主页仓库。独立构建项目子路径时可使用：

```sh
VITE_BASE_PATH=/CamLensSim/ npm run build
```

当前目录仅准备源码与工作流；创建远程仓库、开启 Pages 和实际发布需要在对应 GitHub 仓库中执行。部署流程依据 [Vite 官方静态部署说明](https://vite.dev/guide/static-deploy.html#github-pages)。相机投影依据 [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)。

## 场景资源与视觉边界

人物头部的图形资产来自 MakeHuman 的 CC0 基础网格与女性形态目标，已派生、平滑并打包为本地数据；来源及重建命令见 [资源说明](src/scenes/assets/README.md)。其余模型使用程序化几何。参考图用于指导内容、布局、配色与光线，当前实现不等同于照片级复刻或完整人物扫描。

湖面使用平面反射捕捉实际场景，再叠加静态细波纹和菲涅耳混合；均衡 / 节能档分别使用 1024×512 / 512×256 反射目标。景深后处理仍读取水面的深度，反射中物体的虚像对焦距离尚未独立建模。
