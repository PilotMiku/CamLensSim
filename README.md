# CamLensSim

一个运行在浏览器里的摄影光学实验室。通过室内静物、室外高山湖畔、室外人像、林间知更鸟四个实时三维场景，探索焦距、光圈、传感器尺寸、对焦距离、特殊镜头与自由机位的关系。

在线访问：[CamLensSim](https://pilotmiku.github.io/CamLensSim/)。

当前是可扩展的第三阶段 MVP。原始需求保留在 [writing-block.md](writing-block.md)。无后端、无 API Key、无远程场景资源，场景在本地构建；人物头部使用随源码提供的 CC0 人体网格，其余几何、材质和灯光由本地程序生成。

## 本地运行

需要 Node.js 22.12+，推荐 Node.js 24。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，通常为 http://127.0.0.1:5173。

```sh
npm test                 # 光学、机位、状态、场景几何与资源释放测试
npm run typecheck        # TypeScript 检查
npm run build            # 检查类型并生成 dist/
npm run preview          # 预览生产构建
npm run test:e2e         # 桌面 / 移动端 Chromium 浏览器验证
```

浏览器测试默认使用本机 Google Chrome；如果使用 Playwright 自带 Chromium，先运行 `npx playwright install chromium`，然后执行 `PLAYWRIGHT_CHANNEL=chromium npm run test:e2e`。GitHub Actions 在 PR 和发布前运行全部桌面浏览器测试，以 ANGLE/SwiftShader 执行实际 WebGL2 着色器；测试失败会阻止发布并保存诊断文件。

## 自由机位

取景器就是一个可以走进去的摄影棚：

- 桌面端：`W` `A` `S` `D` 前后左右移动，`J` / `K` 水平转向，`I` / `O` 俯仰，`R` / `F` 升降，`Shift` 加速、`Alt` 慢速。方向键也可以转向。
- 在画面上按住拖动可环视，滚轮前后推拉；短按（不拖动）则对焦到该位置的物体。
- 手机 / 平板：左右两个虚拟摇杆分别控制移动与转向，左侧的 `+` / `−` 控制机位升降。也可以在工具栏手动开关摇杆。
- 「自动跟焦」开启时，焦点锁定在画面中的物体上，移动机位会持续重算对焦距离；关闭后是手动对焦，机位移动后需要重新对焦。
- 对焦距离覆盖镜头最近对焦距离至 100 km；可点击「对焦到无穷远 ∞」、输入 `∞` 或将对焦滑块拖到最右端。无穷远属于手动对焦，移动机位或更换镜头后保持；点按物体可重新对焦，开启自动跟焦则回到物体焦点。
- 「复位机位」回到默认取景；「重置参数」恢复全部拍摄设置。

## 已接通的功能

- 焦距、光圈、对焦距离、机位距离 / 高度：滑块调整，或输入数字并按 Enter / 移开焦点确认。
- 全画幅、APS-C、M4/3、中画幅传感器；相机纵横比与取景器同步变化。
- 22 支镜头：自定义 10–1200 mm f/0.95–32、大三元 / 小三元变焦、常见定焦大光圈、300 f/2.8 与 600 f/4 超长焦、移轴、鱼眼、折返；自动应用焦距、最大光圈与最近对焦距离限制，光圈按三分之一档取整。
- 四个按 `预览/` 参考图重建、带独立光源的场景：**室内静物**（支持光追的封闭工作室、真实开口的窗户、窗外枝叶、白花陶瓶、茶具、木桌与垂坠亚麻布）；**室外高山湖畔**（侵蚀山脊与积雪、实时湖面倒影、树荫、草甸野花与步道）；**室外人像**（樱花步道、CC0 人体头部网格、黑长直发、水手服 JK 与百褶裙、条纹过膝袜与春日下午日照）；**林间知更鸟**（实际尺度的连续鸟体、分层羽毛、覆苔树枝、地衣与多层树林）。
- 场景标题旁的「参考图」可查看原图，便于对照构图；参考图不会替代三维取景器。
- 对焦成功会播放短促双音，可通过取景器的“音效”按钮静音；声音由浏览器本地合成，无需加载音频文件。
- 点击画面中的物体对焦；点击距离示意条中的物体标记对焦。
- 实时水平 / 垂直 / 对角视角、裁切系数、35mm 等效焦距、景深近界 / 远界 / 总范围、超焦距与放大率。放大率统一显示为三位有效数字的倍率（如 0.25×、1×、2×）；1× 表示等大成像，无穷远显示 0×，极小正值仍保留有效数字。此数值为薄透镜近轴参考，移轴时表示光轴交点处的水平倍率。
- 基于有符号弥散圈、光圈叶片多边形核、衍射与屏幕空间采样的景深预览，可关闭对照。
- “模式”可切换 **实时 / 光追**。光追基于 [three-gpu-pathtracer 0.0.24](https://github.com/gkjohnson/three-gpu-pathtracer/tree/v0.0.24)（MIT）与 three-mesh-bvh：将实例化草木烘焙为可求交的 BVH 几何，最多计算 6 次反弹及透射路径，提供反射、折射、几何遮挡阴影、间接光照和薄透镜景深。湖面在光追中使用水的物理材质。机位停止后逐步累积至 128 次采样，每次完整采样后使用深度与表面颜色引导的三轮保边降噪，降低 28 次等低采样下的颗粒；降噪强度随采样数减弱，调整参数后重置，滤波结果不写回原始累积。首次构建场景需要等待，首个采样完成前显示实时画面。精细 / 均衡 / 性能 / 流畅四档分别采用原生取景器宽高的 100% / 85% / 70% / 50%，光追不再额外缩放。
- 光追无穷远对焦使用 1 亿米的有限对焦距离近似，以适配光追库；实时模式与光学数据使用精确的无穷远极限。光追目前支持普通透视及镜头平移；鱼眼、折返、镜头倾斜使用实时模式，并显示提示。光追与实时模式使用同源的晴天下午天空环境，自定义光栅着色器会转成物理材质；暂未将实时模式的衍射与暗角后处理接到光追输出。设备不支持浮点渲染或初始化失败时显示原因并回到实时预览。
- 太阳在实时模式中使用方向光与按遮挡距离估计半影的软阴影，在光追中使用视直径约 0.533° 的远距离圆面光源，参与直射光、BVH 遮挡、反射与多次反弹。天空环境不再额外写入太阳日轮能量；日轮背景和光追反射共用太阳辐射亮度，太阳不是 BVH 中的遮挡网格。三个室外场景采用与天空日轮一致的侧前方日照，并使用完整天空环境补光；路灯外壳采用漫反射为主的喷漆金属材质，使背光处仍能辨认灯杆和灯罩。浏览器测试会关闭灯泡和天空，仅保留太阳，并检查太阳强度变化是否对应灯体反射亮度变化。
- 四个场景统一为晴天下午 16:00，各有六面天空盒与同源 HDR 环境光，太阳高度约 28°。太阳的方向、颜色和强度由独立光源统一提供，光追转换为有限视角圆面；室外高山湖畔、人像和知更鸟场景的人工光源为步道旁的实体路灯，底座贴合地形、灯头向步道投光；室内人工光源为固定在 3.6 m 天花板上的吊灯，带顶盘、吊线、灯罩和发光面。太阳圆面与灯具聚光源分别进入光追灯光列表，灯杆、灯罩和发光面也进入 BVH，参与遮挡、反射与间接照明；光源保持世界坐标固定。室内通过真实窗洞采光，窗格与枝叶的遮挡产生丁达尔光束。实时与光追共用稳定的单次体积散射：沿视线进行世界空间光线步进，用各光源的阴影贴图判断遮挡，并计算透射衰减；聚光灯计算有限光锥的射线交点，再以稳定的中点步进积分，避免窄光束颗粒化；半分辨率渲染、按深度上采样，精细 / 均衡 / 性能 / 流畅分别使用 64 / 64 / 48 / 32 步。光追在降噪后叠加体积光，不再随机采样空气体积，避免低采样时雾中闪点；体积光是混合近似，不计算多次散射与体积间接光。
- 恒定曝光预览；关闭后光圈、快门与 ISO 会真实改变画面亮度，散粒噪声与读出噪声随进光量变化，ISO 同时放大信号和噪声，镜头带暗角与衍射软化。
- 移轴（倾角与水平 / 垂直偏移）、鱼眼等立体角投影、折返环形（甜甜圈）光斑等特殊光学。
- 三分构图线、参数重置、机位复位、帮助说明与四档渲染质量。
- 响应式布局；无 WebGL 时保留光学计算和参数操作，显示明确的预览不可用提示。

## 光学约定与限制

世界坐标、机位距离和对焦距离使用 **米**；焦距、传感器尺寸与弥散圈使用 **毫米**。镜头看向自身光轴，室内默认机位在 `(0, 1.20, 4.60)`、俯角 2°，主体中心平面为 Z = 0。

视角为 `2 atan(传感器边长 / (2 × 焦距))`，这是无限远对焦的标称视角。实际渲染使用对焦距离对应的像距 `v = f·s/(s−f)`，因此近距对焦时会轻微收窄视角，即对焦呼吸。裁切系数使用全画幅与当前传感器的对角线之比；等效焦距用于比较对角视角，**不代表景深或曝光等效**。

景深使用薄透镜模型，容许弥散圈 `c = 传感器对角线 / 1500`，对应约定观看条件下的可接受清晰标准，不是像素大小。令焦距为 `f`、光圈 f 数为 `N`、对焦距离为 `s`，计算时全部换算为毫米：

```text
q = f² / (N × c)
超焦距 H = q + f
近界 Dn = q × s / (q + s − f)
远界 Df = q × s / (q − s + f)，s ≥ H 时为 ∞
物距 u 的弥散圈直径 = f² × |s − u| / (N × u × (s − f))
```

使用 `q = H − f` 的边界公式，与上述像面弥散圈定义保持一致；在超焦距处远界为无穷远、近界为 H/2。对焦至无穷远时，像距为 f、放大率为 0、景深近界为 H−f，有限物距 u 的几何弥散圈直径为 f²/(N·u)。

渲染在几何弥散圈之外再叠加波长 550 nm 的艾里斑 `2.44 × λ × N`，两者按平方和合成，因此 f/16 之后即使景深很深，绝对锐度也会被衍射限制。光圈叶片数会改变焦外光斑的多边形形状。

曝光值 `EV₁₀₀ = log₂(N² / t) − log₂(ISO / 100)`。开启「恒定曝光预览」时固定显示曝光倍率；关闭后按参考曝光归一化，倍率不作上下限截断。ISO 可选 50–25600，快门可选 30 s–1/8000 s；实时和光追均在最终合成阶段施加曝光，改变 ISO、快门或恒定曝光开关不会重置光追累积。极端曝光可能在显示端呈现纯白或纯黑，这是 ACES 色调映射与显示范围的结果；中间 HDR 保留未曝光数据。此模型展示相对曝光变化，未校准场景绝对亮度、镜头透光率或真实相机测光。实时与光追在最终合成时共用虚拟传感器噪声模型；暗角目前仍仅用于实时模式。

虚拟噪声模型采用光子转移模型的信号相关方差与读出噪声项，原理参考 [EMVA 1288 的线性噪声模型](https://www.emva.org/wp-content/uploads/EMVA1288-3.1a.pdf)，不代表通过该标准的器材测量。设 `H = (t × 125) × (1.8/N)²`、`A = 传感器面积 / 864 mm²`，虚拟电子换算系数 `Q = 12000 × H × A`，输入读出噪声固定为 2 e⁻。未曝光线性颜色 L 的噪声方差为 `L/Q + (2/Q)²`，用独立 RGB 高斯样本近似，黑电平以下裁零，再统一施加曝光与色调映射。ISO 不进入光子数量，而在曝光阶段同时放大信号与噪声；因此单独提高 ISO 不会凭空降低输入信噪比，提高 ISO 并缩短快门维持亮度则会增加噪声，6400 以上不再设平台。

画幅比较假设相同虚拟像素数（参考为 24 MP）、相同量子效率与读出噪声；噪声按预览像素抽样，不模拟真实传感器缩图、Bayer 解码、双增益、暗电流、热像素、量化、满阱容量或厂商降噪。12000 e⁻ 与 2 e⁻ 是未标定的教学设定，不是实际机型数据；极低光子计数仍用高斯近似，不计算离散泊松过程。参数或机位变化生成新的噪声样本，静止时保持，光追累积与降噪不把传感器噪声平均掉。

真实相机主平面位置、复杂像差、滚动快门、运动模糊与相机传感器降噪不建模。直线投影只使用薄透镜像距修正；光追光线从镜头孔径出发，汇聚到轴向对焦平面，再推进至近裁剪面，不以近裁剪面为测距起点。鱼眼镜头使用等立体角（equisolid-angle）投影 `r = 2f·sin(θ/2)`，深度、裁剪、点击对焦与跟焦统一使用径向距离，支持中画幅超过 180° 的对角视野；其景深以理想球面焦面近似，未标定真实镜头的像场弯曲和像差。移轴镜头通过斜向视锥实现平移、通过理想薄透镜的沙姆定律与铰链法则计算倾斜焦平面，折返镜头用环形孔径近似中心遮挡。

移轴倾斜模型采用相机坐标 y 向上、z 向前，正倾角 α 表示镜头向下倾斜。令 f 以米计，s 是焦平面与光轴的交点距离，则清晰平面满足 `z/s − y·sin(α)/f = 1`，铰链位于 `y = −f/sin(α), z = 0`，像距为 `v = f/(cos(α) − f/s)`。因此镜头倾角与焦平面倾角不同；倾角固定、改变对焦距离时，焦平面绕铰链转动。无穷远对焦时仍保留倾斜平面，并非全画面清晰。公式依据 [Merklinger《Focusing the View Camera》31–35 页](https://www.cs.cmu.edu/~ILIM/courses/vision-sensors/readings/FVC16.pdf)。

屏幕空间散焦使用有符号水平弥散圈直径 `f·v/N · (1/s − 1/z − sin(α)/f · y/z)`，CPU 数值与 GPU 共用像距和焦平面系数；垂直平移通过实际视线方向参与计算。倾斜状态下景深读数和距离条仅表示光轴截面，超焦距标为零倾角参考。点按和跟焦考虑相机坐标中的物体高度；需要负光轴截距的点超出当前调焦范围，点按不改变原焦点，跟焦越界会提示。此处仍将倾斜光瞳的椭圆散焦近似为圆形/多边形核，不模拟精确的离轴光瞳投影、真实像差和成像圈边缘遮挡。

**画面虚化是近似视觉模拟。** 场景保存在线性 HDR 中，颜色下采样选取与最近深度一致的表面，减少前后景颜色提前混合。有符号弥散圈区分近景与远景：近景半径先做水平/垂直扩展，再按来源光斑面积归一化，输出预乘透明度的近景层；即使接收像素本身清晰，前方失焦物体也能扩散覆盖它。深度检查限制较远来源覆盖更近表面，合成时按深度上采样，焦内底图保留全分辨率。远景模糊层排除近景来源；近景轮廓内部需要的背景颜色从附近可见的后方表面补齐，无法恢复被完全遮住的内容，也不模拟多层透明遮挡。采样采用相反方向成对的固定圆盘分布，保留光圈多边形与环形核。最大散焦半径仍约为画面宽度的 3.4%、上限 56 px，近景层与背景层各使用精细 64 次 / 均衡 44 次 / 性能 28 次 / 流畅 14 次采样；极细枝叶、低采样覆盖率和复杂遮挡仍有近似误差。这套实时后处理不改变光追薄透镜景深，也不模拟真实镜头像差、光斑渐晕与遮挡衍射。景深数据不依赖预览开关或渲染档位。

渲染质量分为精细（100%）、均衡（85%，默认）、性能（70%）、流畅（50%）。百分比按取景器原生宽高计算，包含屏幕 DPR，实时与光追均只缩放一次；例如原生 1000×800 像素，均衡为 850×680，流畅为 500×400。绘制缓冲尺寸向下取整为整数像素。精细与均衡采用 4×MSAA，性能与流畅关闭 MSAA。静态场景按参数或容器变化请求绘制，空闲时不持续刷新；移动相机时按输入逐帧更新。

VITE_BASE_PATH=/CamLensSim/ npm run build

## 太阳光照模型

当前太阳模型使用平均角半径 α = 0.00465 rad，视直径约 0.533°，参考 [NASA 太阳视直径资料](https://ntrs.nasa.gov/api/citations/20220013453/downloads/TFAWS-2022-Short%20Course-Environments_Vector_Shading_MERGED.pptx.pdf)。光追以距目标 1 亿米、半径 `D·tan(α)` 的圆面近似远距离太阳，使用现有引擎的圆面采样、阴影射线和多重重要性采样；源光强 E 转为圆面辐射亮度 `L = E / (π·sin²α)`，保持法向受光面的总能量。遮挡物与受光面间距为 h 时，理想直边的全半影宽度约为 `2h·tan(α)`，每米约 9.3 mm。

天空 HDR 与天空盒只保存天空补光和大气辉光，日轮不再作为第二份环境光。相机/透射背景用解析日轮，反射和间接光由同一圆面光源计算；实时背景跟随机位平移，太阳方向保持不变，不会因在房间或步道移动而出现近距离视差。实时表面使用遮挡搜索和距离相关 PCF 估计半影，灯具阴影不受影响；空气光束仍是阴影贴图驱动的单次散射近似。光追降噪缓存改为 Float32 保存高亮，实时日轮显示代理受 FP16 范围限制。

这实现了太阳圆面的几何、余弦受光、遮挡与能量关系，整体场景强度仍采用原有的相对标定，并非绝对 lux 测量；不模拟太阳光谱、临边昏暗、地球轨道季节变化或完整大气多次散射。浏览器 GPU 的太阳亮度与半影回归用例已提供，但在当前受限环境中尚未完成实测。
